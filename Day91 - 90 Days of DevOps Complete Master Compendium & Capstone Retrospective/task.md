## 🏆 The 10 Immutable Laws of Production Engineering
1. **Zero-Drift Mandatory**: If an environment cannot be rebuilt from version-controlled declarative code in 15 minutes, it is already legacy technical debt.
2. **Don't Guess. Investigate**: Never guess a root cause from an error message string. Inspect kernel signals, system calls, and distributed traces.
3. **Containers are Cattle, Not Pets**: Build with minimal distroless base images, non-root users, and read-only root filesystems.
4. **Defense-in-Depth Security**: Shift left. Scan code with SAST, scan images with Trivy, generate SBOMs with Syft, and sign with Sigstore Cosign.
5. **Idempotence is Non-Negotiable**: Running an automation script 1 time or 100 times must yield the exact same deterministic state.
6. **Telemetry Before Launch**: A service without metrics, logs, and trace context propagation is unobservable and cannot be operated safely.
7. **Automate Failure Testing**: Do not wait for a live incident to test failover. Run Chaos Mesh and DR drills on schedule.
8. **Automated Recovery Beats Paging Humans**: If an error can be trapped (`trap cleanup EXIT INT TERM`), automate self-healing before waking up an on-call engineer.
9. **Single Source of Truth**: Git is the single source of truth. Imperative cluster edits (`kubectl edit`) are forbidden.
10. **Build in Public & Document Everything**: The highest form of engineering mastery is the ability to communicate complex architectures with clarity.
